# Virtualização de servidor Tomcat e PostgreSQL com Vagrant

## Como clonar esse repositório:

```
git clone --recurse-submodules https://github.com/SwagMessiah02/vagrant-app
```

## Como subir as VMs:

```
cd vagrant-app
vagrant up
```

## URL HTTP: 

```
http://localhost:8080/user-auth-0.0.1-SNAPSHOT/user/login
```

# URL HTTPS (Somente se for habilitado):

```
https://localhost:8443/user-auth-0.0.1-SNAPSHOT/user/login
```
